(หน้า `src/app/page.tsx` เช็คว่าไฟล์มีจริงไหมตอน build ถ้ายังไม่มีจะใช้ไอคอนแบรนด์แทน
จึงไม่มีทางเกิดไอคอนภาพแตกระหว่างที่ยังหารูปไม่ครบ)

## ข้อกำหนดรูป

- อัตราส่วน **4:3** (เช่น 1200×900 px) — อัตราส่วนอื่นจะถูก crop กลางภาพด้วย `object-cover`
  ตอนแสดงผล **ซึ่งมักตัดของสำคัญหาย** (สกรีนช็อตแนวนอนโดนตัดคอลัมน์ซ้าย/ขวา)
  ถ้ารูปต้นฉบับไม่ใช่ 4:3 ให้ทำเป็น "ภาพลอยบนพื้นพีช" แทนการ crop — ดูหัวข้อข้างล่าง
- รองรับ **`.png` · `.jpg` · `.jpeg` · `.webp`** (ลำดับความสำคัญตามนี้ — วาง `.png`
  ทับทีหลังจะชนะ `.webp` ที่ optimize ไว้เสมอ เปลี่ยนรูปได้โดยไม่ต้องตามลบไฟล์เก่า)
- ควรไม่เกิน ~150 KB ต่อไฟล์ — หน้านี้เป็นหน้าแรกที่ทุกคนเปิด และเปิดจากมือถือเป็นหลัก
  (WebP q88 ที่ 1200×900 อยู่ราว 40–90 KB คุณภาพตาแทบไม่ต่างจาก PNG ที่ใหญ่กว่า 5 เท่า)
- รูปถูกแสดงแบบ "ลอย" บนพื้นหลัง มุมมนและมีเงา **ไม่มีกรอบครอบ**

## วิธีเตรียมรูปจากสกรีนช็อตดิบ

สกรีนช็อตหน้าเว็บมักเป็นแนวนอน (~16:9) ซึ่ง crop เป็น 4:3 แล้วเสียของ — วิธีที่ใช้กับ
`price-list.webp` คือวางภาพทั้งใบลอยบนพื้นไล่เฉด rose gold มุมมน + เงานุ่ม ให้เข้าชุดกับ
mockup ของทีม ทำด้วย sharp (มีใน devDependencies อยู่แล้ว):

1. พื้นหลัง 1200×900 ไล่เฉด `#fdf7f2 → #f7e6db → #efd6c8`
2. ย่อสกรีนช็อตให้กว้าง ~86% ของพื้นหลัง แล้วมนมุม 22px (composite SVG mask แบบ `dest-in`)
3. วางเงา (สี่เหลี่ยมมน `rgba(94,58,49,0.4)` เบลอ 22) ไว้ใต้ภาพ เยื้องลง 16px
4. บันทึกเป็น `.webp` quality 88
